# Zuno

## What it does

A timer app that tracks time across time zones: a world map, a month grid of weekends and public
holidays, and a meeting-time picker for the places you add. Each place is a city from a fixed list
of 55 cities. The settings panel holds the places,
the working hours, the display switches and the theme (Light, Dark, or Auto, which follows your
system).

## Stack

Plain JavaScript, HTML and CSS, bundled into one file by esbuild 0.28.2. Browser tests use Playwright 1.65.1 (dev-only). Versions of every tool are in `package.json`.

## File structure

| Path | Holds |
| --- | --- |
| `src/` | All source code. |
| `tests/` | `unit/` and `e2e/` tests. |
| `data/` | `cities.js`: the 55 cities you can add, with their country, time zone and map position. |
| `dist/` | The built one-file page `zuno.html`. Generated by `npm run build`; not committed. |
| `docs/` | Workflow, spec, design, and plan. |
| `config/` | `.env` (never committed) and `.env.example`. |
| `scripts/` | `check.py` (the checks), `milestones-runner.py`, `cleanup.py`, setup scripts. |
| `.claude/` | Claude Code settings, including the hook that checks each edit. |
| `.githooks/` | `pre-commit`: refuses a commit unless the checks pass. |
| `.vscode/` | Shared editor settings. |

## Setup

```bash
npm install
npx playwright install chromium firefox webkit
```

The second command downloads the three browsers that the browser tests drive. The fourth, Microsoft
Edge, is not downloaded: the tests use the Edge installed on the machine (the `msedge` channel). The
page needs no configuration and no server.

After a fresh clone, turn on the pre-commit hook, which refuses a commit unless the checks pass:

```bash
git config core.hooksPath .githooks
```

## How to run

Build the one-file page, then open `dist/zuno.html` in a browser:

```bash
npm install
npm run build
```

## How to test

```bash
npm test
npm run typecheck
npm run lint
npm run lint:css
npm run format:check
```

`npm test` also runs the headless-browser tests in `tests/e2e/ui/`. They build the page into a
scratch folder, open it as a file in Chromium, Firefox, WebKit and Edge, and answer the holiday
service by request routing, so they need no network.

`npm test` also measures coverage of `src/` and fails below 80% for lines or branches.
