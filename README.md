# Zuno

## What it does

A timer app that tracks time across time zones.

## Stack

Plain JavaScript, HTML and CSS, bundled into one file by esbuild 0.28.2. Browser tests use Playwright 1.65.1 (dev-only). Versions of every tool are in `package.json`.

## File structure

| Path | Holds |
| --- | --- |
| `src/` | All source code. |
| `tests/` | `unit/` and `e2e/` tests. |
| `dist/` | The built one-file page `zuno.html`. Generated by `npm run build`; not committed. |
| `docs/` | Workflow, spec, design, and plan. |
| `config/` | `.env` (never committed) and `.env.example`. |
| `scripts/` | `check.py` (the checks), `milestones-runner.py`, `cleanup.py`, setup scripts. |
| `.claude/` | Claude Code settings, including the hook that checks each edit. |
| `.githooks/` | `pre-commit`: refuses a commit unless the checks pass. |
| `.vscode/` | Shared editor settings. |

## Setup

```bash
npm install
npx playwright install chromium
```

The second command downloads the browser that the browser tests drive. The page needs no
configuration and no server.

After a fresh clone, turn on the pre-commit hook, which refuses a commit unless the checks pass:

```bash
git config core.hooksPath .githooks
```

## How to run

Build the one-file page, then open `dist/zuno.html` in a browser:

```bash
npm install
npm run build
```

## How to test

```bash
npm test
npm run typecheck
npm run lint
npm run lint:css
npm run format:check
```

`npm test` also runs the headless-browser tests in `tests/e2e/ui/`. They build the page into a
scratch folder, open it as a file in Chromium, and answer the holiday service by request routing,
so they need no network.
